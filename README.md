# 중랑구 나눔가게 지도 ver. 1

중랑구의 나눔 가게들을 살펴볼 수 있는 지도를 만들고 싶어

이걸 사용하도록 해

비단방앗간도 식품에 넣자

식품, 외식, 식료품을 합쳐줘

의류 생필품도 합치자

가게를 누르면 그 가게 위치를 지도로 볼 수 있도록 코딩해줘(구글지도)
